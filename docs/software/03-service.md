# Tablo — софт: сервис (§6)

> Часть проекта софта, индекс — [`docs/README.md`](../README.md). Номера §N сквозные по всем частям.

## 6. Сервис

### 6.1 Стек

- **Python 3.12, один процесс asyncio.**
- `aiohttp` — веб-сервер, WebSocket к плате, HTTP-клиент, WebSocket к HA. Одна библиотека на всё, чтобы не тянуть FastAPI + uvicorn + httpx.
- `Pillow` — вёрстка, без браузера.
- `icalendar`, `segno` (QR), `jinja2` (шаблоны дома в поддельном HA).
- LLM в Tablo нет: Haiku вызывает infomaster.
- **SQLite** (`data/tablo.db`) — одна таблица `kv`: последние удачные ответы infomaster, лента пар, погода. Старые таблицы (оценки, новости, свои дедлайны, словарь, прогоны LLM) после перехода на infomaster не используются: остаются в существующей базе для отката, базу можно начать заново. Ключи прежних источников (`hseapp.auth` — токен the university app, разметка таблиц, метки HSE) сервис удаляет при старте.

### 6.2 Внутреннее устройство

```
источники ──▶ хранилище (SQLite + память) ──▶ модель экрана ──▶ рендер (Pillow) ──▶ кадр ──▶ плата
   ▲ расписание каждого                         (чистые данные)    1 бит, CRC
   └ события HA (мгновенно)
```

- **Источники** — независимые модули с интерфейсом «забери данные, верни типизированные записи»: infomaster (раз в минуту), лента `tablo.ics` (раз в 10 мин), погода (раз в 15 мин). У каждого своё расписание, кэш и флаг «последний раз успешно». Ошибка одного не ломает остальные: блок показывает последние известные данные.
- **Модель экрана** — чистые данные без пикселей: «3 дедлайна», «прогноз на 8 часов», «плитка 3 включена». Её можно сравнивать и тестировать.
- **Рендер** превращает модель в картинку. Раскладка — координаты в одном файле.
- Изменилась модель → через 2 с рендер → если CRC другой, кадр уходит на плату.

### 6.3 Вёрстка

- Текст основного экрана (Inter 15 и 16 medium, 16 и 30 semibold) — пиксельные шрифты: текстовые файлы `assets/fonts/pixel/`, по знаку на блок `#`/`.`. Их сделал `tools/pixel_fonts.py` из монохромного рендера FreeType, вертикальные ножки в 1 px он утолщает до 2 px. Буквы и цифры стоят на общих линиях (верх заглавных, цифр, строчных, базовая), свес круглых форм на пиксель срезан, `--align`. Остальное поправлено руками: дефис, кавычки, m, e, w, r. Базовая линия у строки одна, а PIL сдвигал строку на пиксель в зависимости от букв. Знака нет в файле — он рисуется через FreeType. Оверлеи (20–34 px) рисует FreeType: `fontmode="1"` или рендер в оттенках серого с порогом (`font_mode`). Окончательно сравним на живой панели. Те же растровые шрифты пригодятся прошивке для часов и строки статуса (§10).
- Текст, который не помещается, обрезается с «…».
- Значки погоды — свои, одной линией, как в макете: солнце, луна, облако, облако с 1–3 штрихами, снег, гроза, туман. Нарисованы попиксельно (`render/pixels.py`): 44 px для текущей погоды с линией 3 px и 22 px для почасовой строки с линией 2 px. Векторные линии в 1 бит на таких размерах рвутся. У всех значков с осадками одно и то же облако, поэтому облака в строке стоят на одном уровне.
- Постоянные значки блоков 15 px (книга, человек, шапочка, конверт, самолётик, календарь, дом, восклицательный знак) тоже попиксельные, по форме значков MDI. Значки, для которых пиксельной версии нет, берутся из шрифта MDI.
- **Значки кнопок — Material Design Icons** из файла шрифта MDI. Имя `mdi:lamp` переводится в символ шрифта по `meta.json`, размер 32 px. Это те же имена, что в HA.
- Срочный дедлайн выделен инверсией.

### 6.4 HTTP API

Для интеграции HA и отладки, на том же порту 8765. Запросы, меняющие состояние, а также `GET /api/config`, требуют `Authorization: Bearer <api_token>`.

| Метод и путь | Что делает |
|---|---|
| `GET /api/config` | Текущий конфиг без секретов: интеграция берёт его при подключении (§8.1) |
| `PUT /api/config` | Интеграция присылает полный конфиг (§8) |
| `POST /api/overlay/qr` | `{networks: [...], duration_s}` |
| `POST /api/overlay/message` | `{title, text, icon, duration_s, sticky}`: `sticky: true` — висящее сообщение в очередь, `duration_s` не нужен (§5) |
| `DELETE /api/messages` | Очистить висящие сообщения и снять экран с платы; ответ `{cleared: N}` |
| `POST /api/refresh` | `{full: bool, refetch: bool, sources: [...]}`: `refetch` опрашивает источники сейчас (`infomaster`, `ical`, `weather`; без `sources` — все). У infomaster «обновить сейчас» нет: Tablo только заново читает его API |
| `GET /api/status` | Состояние платы, источников, HA; `firmware` — выложенная прошивка (`size`, `md5`) или `null`; `messages` — висящие сообщения (`title`, `sent_at`, старые первыми); `infomaster` — `ok_at`, `error`, `down`; `hseapp` — статус the university app из infomaster и `login_needed` для уведомления HA (§8.4) |
| `GET /frame.png` | Текущий кадр картинкой |
| `PUT /api/firmware` | Тело — `firmware.bin` (до 1,9 МБ, первый байт `0xE9`). Сервис держит образ в памяти и шлёт подключённой плате `ota` (§3.3); нет платы — 409. Ответ `{size, devices}`. С Мака: `pio run -e service -t upload` (§10) |
| `GET /firmware.bin?token=<device_token>` | Плата скачивает выложенный образ своим токеном; не выложен — 404 |
| `GET /emu` | Эмулятор (§9) |

### 6.5 Конфигурация

- **Секреты** — в `.env` сервиса: токен HA, токен infomaster (`TABLO_INFOMASTER_TOKEN`), токены платы и API (§13).
- **Содержательные настройки** (кнопки, ссылка на ленту пар, погода, дом, экран) — в HA. Настройки дедлайнов, новостей и оценок — в Mini App infomaster. Интеграция присылает их через `PUT /api/config`.
- Сервис хранит последний полученный конфиг на диске и работает по нему, даже если HA недоступен.
- Пока интеграции нет (этапы 1–6), тот же конфиг читается из `config.yaml`. Схема одна и та же.

### 6.6 Прогоны LLM

Убраны вместе с Haiku: расход LLM считает и показывает infomaster (экран «Расход LLM» в Mini App). Ни в Tablo, ни в HA его нет.
