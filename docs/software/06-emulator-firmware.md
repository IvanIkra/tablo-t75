# Tablo — софт: эмулятор и прошивка (§9–10)

> Часть проекта софта, индекс — [`tablo-software.md`](../../tablo-software.md). Номера §N сквозные по всем частям.

## 9. Эмулятор

Страница `http://<сервис>:8765/emu`, которая повторяет логику прошивки на JavaScript.

- Подключается по **тому же протоколу**, что и плата. Сервис не отличает её от железа.
- Холст 800×480, масштаб 1× или 2×, цвета «под бумагу».
- Сама рисует часы, дату и строку статуса (со значком infomaster при `data: false`) по зонам из `config`, в часовом поясе из `config`. Время и дату — из тех же пиксельных шрифтов, что и сервис (`/fonts/pixel/clock-64.txt` и `Inter-Medium-16.txt`, §6.3). Если шрифты не загрузились, рисует обычным Inter.
- **Кнопки:** 8 кнопок под экраном. Клик — короткое нажатие, удержание ≥ 600 мс — долгое, клавиши `1`–`8`. Мгновенная инверсия плиток, откат по `button_result`, полноэкранные экраны с `ttl`, своя диагностика на 8-й.
- **Отладка:** подсветка прямоугольников частичного обновления, переключатель «сервис недоступен» (рвёт соединение), журнал сообщений протокола.
- Работает в браузере на Маке и памяти сервера не занимает.

## 10. Прошивка

Код — `firmware/` (PlatformIO + Arduino), тест экрана — `firmware/bringup/`. Здесь — то, что важно для протокола и сборки.

- Библиотеки: `GxEPD2` (драйвер `GxEPD2_750_GDEY075T7` напрямую, без буфера `GxEPD2_BW`), `arduinoWebSockets`, `ArduinoJson` 7. У `arduinoWebSockets` жёсткий лимит сообщения 15 КБ без `#ifndef`; скрипт `tools/patch_websockets.py` поднимает его до 64 КБ перед сборкой (кадр — одно сообщение 48 020 байт).
- Разметка флеша `min_spiffs.csv`: два раздела программы по 1,9 МБ для OTA. В стандартные 1,25 МБ Wi-Fi + WebSocket + OTA не влезают.
- Подключение экрана к ESP32-L через DESPI-C02: CS 27, DC 14, RST 12, BUSY 13, SCK 18, MOSI 23; импульс сброса 2 мс. Заливка по USB надёжна на 115 200, на 921 600 срывается.
- **Живая панель (30.10.2026):** полное обновление 2,3 с (сама панель 1,55 с), частичное окна 240×120 — 0,44 с, частичное всего экрана — 0,62 с; разница — передача 48 КБ по SPI на скорости GxEPD2 по умолчанию, её можно поднять. Картинка чёткая, края и линии в 1 px видны; после серии частичных — лёгкие следы прошлого.
- Память: основной кадр 48 КБ + показанное на экране 48 КБ (с ним сравнивается новый кадр) + на время приёма буфер библиотеки 48 КБ. Новый кадр собирается построчно: строка основного кадра, поверх зоны прошивки, сравнение со строкой на экране. Частичное обновление — прямоугольник изменённых байтов; большая смена — полное (§3.4). Через 5 с без обновлений питание панели выключается.
- Время — NTP, пояс из `config` (`MSK-3`). Пока время не получено, зона часов пустая. Шрифты и значки — те же пиксельные файлы сервиса (`clock-64`, `Inter-Medium-16` для даты, `Inter-SemiBold-16` для плашки offline, `Inter-SemiBold-30` для диагностики) и значки MDI 17 px, переведённые в таблицы C: `service/.venv/bin/python firmware/tools/gen_assets.py` → `src/assets.{h,cpp}`. Цифры часов одной ширины: `HH:MM` всегда 174 px.
- 8 кнопок на GPIO. Какие пины свободны после SPI экрана — проверим на плате: 34–39 только на вход и без подтяжки, strapping-пины не трогаем.
- Wi-Fi, адрес сервиса, токен и пароль OTA — в `include/secrets.h` (образец `secrets.example.h`, сам файл не в git). Обновление по воздуху: `pio run -e ota -t upload` с `TABLO_OTA_PASSWORD` в окружении. USB-C платы выведен наружу, так что прошить можно и без разборки.
- **Перед первой прошивкой:** сервис на хосте пока принимает токен платы по умолчанию из кода. Сгенерировать свой (`python3 -c "import secrets; print(secrets.token_urlsafe(32))"`), записать `TABLO_DEVICE_TOKEN=…` в `~/tablo/.env` на хосте и в `service/.env` на Маке, пересоздать контейнер (`docker compose up -d --force-recreate`) и тот же токен — в `secrets.h`. Эмулятор после этого открывать как `/emu?token=…`. Токен API (для HA) уже свой с 18.10.
