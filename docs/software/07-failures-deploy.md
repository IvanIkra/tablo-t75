## 12. Развёртывание и ресурсы

**Разработка** — на Маке, сервис ходит в настоящий HA на `192.168.1.50:8123`.

**Боевой запуск** — Docker Compose на `server`:
- Сеть bridge, порт открыт только на LAN-адресе хоста, DNS задан явно (`dns:`). Не `network_mode: host`: при нём контейнер берёт DNS хоста, а HA однажды уже ломался из-за этого.
- HA доступен по `192.168.1.50:8123`.
- Том `./data` для SQLite и сохранённого конфига.
- `mem_limit: 256m`.

**Бюджет памяти** (оценка, проверим замером):

| Состояние | RSS |
|---|---|
| Ожидание | 80–120 МБ |
| Рендер кадра | +10–20 МБ на пике |
| Разбор таблицы на 2,4 МБ (openpyxl, read-only) | +20–40 МБ на пике |

CPU в ожидании около нуля. Если понадобится меньше — `anthropic` и Google-часть грузятся только на время запроса.

## 13. Секреты и приватность

| Секрет | Где хранится |
|---|---|
| Токен HA, ключ Anthropic, пароль приложения Яндекса, токены платы и API | `.env` сервиса |
| Ссылка iCal, пароли Wi-Fi для QR | Настройки интеграции в HA (`.storage`) |
| Токен the university app (`refresh_token`) | SQLite сервиса, продлевается ежечасно; окно 21 день |

- В репозиторий секреты не попадают: в нём только `.env.example`.
- Сервис слушает только локальную сеть, наружу не публикуется.
- **Таблицы оценок** содержат данные всех одногруппников. Сервис хранит только свою строку, Haiku видит только шапку и свою строку. Тестовые таблицы в репозитории — только обезличенные.
- **Письма** отправляются в Anthropic целиком (решение пользователя). Рассылки можно отсечь фильтром до Haiku.
